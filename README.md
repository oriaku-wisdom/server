
A comprehensive implementation of **ActiveRecord-style database associations** establishing relationships between key models. This task ensures data integrity, cascading deletions, and seamless data retrieval using standard Object-Relational Mapping (ORM) design patterns.

## 🚀 Features

* **One-to-Many Relationships:** Links parents to multiple child records seamlessly.
* **Many-to-Many Jointures:** Connects independent tables using fully tracked join tables.
* **Cascading Deletions:** Automatically cleans up orphan data when a primary model is deleted.
* **Eager Loading Optimization:** Built-in scopes to avoid performance-killing N
